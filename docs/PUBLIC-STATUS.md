# 公开状态与证据边界（2026-10-29）

当前工程提供固定任务运行、Prompt/Skill 候选生成、门禁、审查与回滚，以及用户材料问答和文献工具。公开 `public-task-input-v1` 允许读者用自备、带来源和许可的 JSONL 从准备、冻结走到评测。多 seed、消融、开放反馈候选晋升、受控 OA 全文和可选 PaperQA 文档记录适配有独立入口及隔离工程测试。真实模型和数据集实验仍需单独准备输入、冻结协议与费用上限。

截至 2026-10-19 的本地实验记录显示：当前固定候选没有取得可支持公开宣称的正向泛化收益；语义判分校准和自然候选审查分布仍有适用性限制。因此本公开版本不宣称“自进化持续提高科研质量”或“完整科研效能已通过验收”。这些是研究结论的边界，不妨碍使用已实现的工程流程。

公开快照不包含封存评测题、原始模型响应和本地 `.workbuddy/` 实验目录。原研究仓库中的历史报告所引用的部分逐请求收据与重算脚本依赖这些本地目录；公开仓库读者不能据此独立重跑历史分数。新实验应从独立数据和新的预注册计划开始，不得把已曝光任务重新称为未见测试。

2026-10-29 的合成工程验收完成了真实 Pi 固定任务与真实 HTTP 开放任务的隔离发布/回滚接线；HTTP 开放任务使用明确标记的人工工程提案和程序评分。免费模型自动生成的 Skill 提案未通过独立改善门，已拒绝发布。两类正向验收都不支持真实科研收益声明，摘要与本地收据哈希见[能力验收记录](PUBLIC-CAPABILITY-EVIDENCE-2026-10-29.json)。

[公开聚合证据](PUBLIC-EVIDENCE-2026-10-19.json)记录了源文件哈希、冻结协议身份、两组聚合结果及其局限。`scripts/verify_public_evidence.py` 能检查公开摘要的任务数、配对差值与请求总数；持有原始本地材料时还可校验其文件 SHA-256。没有原始材料时，检查通过不等于独立复现了历史模型实验。

具体支持与停用的能力见 [公开范围](PUBLIC-RELEASE-SCOPE.md)；安装和入口见 [开始使用](GETTING-STARTED.md)。
