# 科研工作台：选型、接口与实施

分支：`codex/research-frontend`；依赖已验收的六阶段工作流。

## 技术选型与接口

使用 Python 标准库本地 HTTP 服务与原生 HTML/CSS/JavaScript，减少部署依赖。服务仅绑定 `127.0.0.1`，请求校验 Host、Origin 和进程会话令牌；异步执行单个任务，界面轮询阶段状态。接口覆盖任务提交和状态、答案及引用、经明确授权的反馈；所有数据由现有运行时和反馈模块处理。

## 实施与验收

1. 完成问题、材料/文献来源选择、阶段进度、回答、证据和反馈页面。
2. 后端和前端校验输入、空状态、错误状态及授权；限制请求大小，记录任务结果。
3. 单元与集成测试验证来源/CSRF 拒绝、任务到引用及反馈；浏览器检查桌面、移动布局和键盘操作。
4. 在集成分支检查 Pi 与文献接口，并在公开快照中包含页面资产和使用文档。
