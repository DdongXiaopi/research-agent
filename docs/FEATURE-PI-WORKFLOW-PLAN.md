# Pi 六阶段工作流：选型、接口与实施

分支：`codex/pi-research-workflow`；依赖文献来源分支的已验收接口，保持现有选择题协议兼容。

## 技术选型与接口

继续使用锁定的 Pi harness、JSONL 会话、既有 Skill 注册表和引用校验；新增开放科研适配器，避免伪装成 HTTP 运行。编排由 Python 负责，阶段为问题解析、Skill 路由、来源检索、证据整理、回答生成和引用核验。`build_plan` 冻结配置、来源计划及版本；`execute` 记录状态、失败、预算、输出和阶段信息。独立评测使用临时 Pi 会话，普通任务保存可核验会话。

## 实施与验收

1. 扩展 Pi 开放回答和任务计划，保证模型请求、会话和引文可追溯。
2. 接入 CLI；检索失败或无材料时明确呈现状态，保留可检查产物。
3. 单元及集成测试覆盖六阶段、真实 Pi harness 的离线模型、无来源、预算、失败、篡改和已有协议回归。
4. 使用公开摘要及受限真实 Pi 模型验证输入到引用输出；通过后在独立集成分支组合其他功能，发布前跑完整公开测试。
