# 公开仓库数据与执行接口修复计划（2026-10-29）

## 范围与原则

修复 2026-10-29 复核确认的四项工程缺口：重复题目 ID、数据准备失败后残留部分产物、冻结成功状态与封存文件不一致、开放科研 CLI 可绕过调用方计划哈希。保持现有数据集与冻结协议身份不变；真实模型效果、未分发数据及停用的历史入口不在本次修复范围内。原研究工作区存在大量既有修改，公开交付继续从独立白名单快照生成，不推送原 Git 历史。

- 数据准备改为全部输入预检、暂存输出和失败回滚；已有冻结数据集拒绝覆盖。原始 LitQA2/ProtocolQA 在临时副本中准备、冻结、校验通过。

- 开放科研 CLI 未传/错传调用方哈希时拒绝执行；正确哈希的 FakeProvider 回答通过，文献网络与 Skill 模型调度在缺哈希时均未发生。

- 全仓库历史研究测试未在本轮完成一次全量回归；本页只记录实际执行的定向与公开交付检查。文件提交回滚覆盖可捕获的写入错误；断电或进程强制终止不具备跨文件事务保证，冻结校验仍会拒绝内容不一致。
