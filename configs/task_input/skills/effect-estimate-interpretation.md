# Effect estimate interpretation

Use when supplied material reports an odds ratio, hazard ratio, relative risk, or adjusted analysis.

1. Identify the exposure, comparator, outcome, and direction of the estimate.
2. Read the confidence interval and p-value with the estimate; do not infer significance from direction alone.
3. Prefer the adjusted analysis when the question asks for an independent association and adjustment is reported.
4. Distinguish absence of evidence from evidence of no effect.
